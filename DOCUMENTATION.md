# Описание генератора сценариев и программы проверки

## Назначение

Код сравнивает три стратегии уборки прямоугольного поля двумя комбайнами:

1. Деление поля пополам.
2. Распределение проходов через один.
3. Деление пропорционально производительности машин.

Для каждой стратегии строятся маршруты обеих машин, проверяются столкновения и
подбирается задержка запуска. Результат стратегии — время завершения последнего
комбайна.

## Структура программ

- `generate.py` формирует только входные данные 162 сценариев и сохраняет их в
  `synthetic_scenarios.xlsx`;
- `main.py` запускает приложение PyQt, проверяет таблицы и рассчитывает отдельные
  числовые сценарии;
- `planner.py` содержит общую математическую модель маршрутов и импортируется
  программой проверки и генератором.

Установка и запуск:

```powershell
python -m pip install -r requirements.txt
python generate.py
python main.py
```

В `main.py` доступны две вкладки:

- **«Загрузить таблицу»** — выбор входного XLSX, фоновая проверка всех строк,
  отображение прогресса и сохранение результирующего XLSX;
- **«Рассчитать частный случай»** — числовой ввод размеров поля, разворотной
  зоны, параметров и стартовых положений двух машин, сравнение стратегий,
  отображение выбранных маршрутов, сохранение XLSX-отчёта и схемы в PNG.

Программа проверки обрабатывает все строки входной таблицы. Количество сценариев
не ограничено и не обязано совпадать со 162 сценариями штатного генератора.
CSV не используется.

В частном расчёте пользователь вводит фактические числа. Условия `=`, `>` и `<`
для ширины захвата, скорости, длины и ширины машин вычисляются автоматически.
Отчёт частного случая содержит листы `configuration`, `results`,
`route_machine_1` и `route_machine_2`.

## Единицы измерения

- расстояние — метры;
- скорость — метры в секунду;
- время — секунды;
- внешние углы — градусы;
- внутренние углы — радианы.

## Структуры данных

### `Machine`

Описывает один комбайн:

- ширина захвата;
- рабочая скорость;
- скорость переезда;
- скорость разворота;
- длина и ширина корпуса;
- минимальный радиус разворота;
- стартовые координаты;
- начальная ориентация.

Для проверки столкновений корпус и жатка заменяются окружностью:

```text
collision_radius =
    sqrt((length / 2)² + (max(width, header) / 2)²)
    + safety_margin
```

### `FieldGeometry`

Хранит направление рабочих проходов, числовые размеры поля и ширину разворотной
зоны. Значения могут поступать из XLSX или из формы частного расчёта.

- `axis="x"` — проходы вдоль оси X;
- `axis="y"` — проходы вдоль оси Y.

Рабочая длина прохода не включает две разворотные зоны:

```text
run_length = field_length - 2 × turn_zone_width
```

### `Segment`

Один участок маршрута:

- начальная точка;
- конечная точка;
- время начала;
- время окончания;
- тип движения.

Типы движения:

- `work` — рабочий проход;
- `deadhead` — порожний переезд;
- `turn` — разворот;
- `wait` — ожидание старта;
- `park` — стоянка после завершения.

### `Route`

Полный маршрут одного комбайна:

- последовательность сегментов;
- общее время;
- рабочий пробег;
- порожний пробег;
- разворотный пробег;
- количество рабочих проходов и межполосных разворотов;
- сторона первого входа;
- порядок обхода проходов.

### `Plan`

Результат проверки одной стратегии:

- допустимость;
- причина отклонения;
- время каждой машины;
- время завершения последней машины;
- задержки запуска;
- порожний пробег;
- площадь перекрытия;
- выбранные маршруты.

## Формирование рабочих проходов

Количество проходов всегда целое:

```text
pass_count = ceil(region_width / header_width)
```

Проходы равномерно размещаются внутри назначенной области. Если её ширина не
кратна ширине захвата, возникает перекрытие:

```text
overlap_width = pass_count × header_width - region_width
```

Площадь перекрытия:

```text
overlap_area = overlap_width × run_length
```

## Стратегии

### 1. Деление пополам

Каждому комбайну назначается половина поперечной ширины поля.

Проверяются два расположения:

- первая машина работает от нижнего или левого края;
- первая машина работает от верхнего или правого края.

### 2. Деление по производительности

Рабочая производительность машины:

```text
P = header_width × work_speed
```

Доля первой машины:

```text
share1 = sweep_width × P1 / (P1 + P2)
```

Оставшаяся ширина назначается второй машине. После этого для каждой области
строится целое число проходов.

### 3. Деление по полосам

Последовательные проходы назначаются машинам через один.

Проверяются два варианта:

- первую полосу получает первый комбайн;
- первую полосу получает второй комбайн.

## Построение маршрута

Для каждого набора проходов проверяются четыре варианта:

- прямой порядок проходов;
- обратный порядок проходов;
- вход с ближней стороны;
- вход с дальней стороны.

Маршрут состоит из следующих действий:

1. Переезд от старта к первому проходу.
2. Поворот к направлению рабочего движения.
3. Выполнение рабочего прохода.
4. Непрерывный радиальный разворот к следующему проходу.
5. После последнего прохода — отвод машины к внешней границе поля.

Переезд к дальней стороне выполняется вдоль периметра. Диагональное движение
через неубранную область не используется.

Если расстояние между проходами не меньше двух радиусов, разворот состоит из
двух четвертей окружности радиуса `turn_radius` и прямого участка между ними.
Для более близких проходов используется петлевой RLR-манёвр из трёх дуг.
Дуги разбиваются на хорды с угловым шагом не более 10°, но время считается по
фактической длине дуги, а не по длине хорды.

Количество разворотов одной машины равно:

```text
turn_count = max(0, pass_count - 1)
```

Сторона расположения разворотных зон задаёт направление рабочих проходов и
тем самым ширину, которую нужно покрыть. При проходах вдоль X число проходов
рассчитывается по размеру поля вдоль Y; при проходах вдоль Y — по размеру X.
Поэтому смена стороны разворотных зон изменяет число проходов, число поворотов
и итоговое время стратегии.

## Проверка разворотной зоны

Маршрут отклоняется, если край радиальной траектории вместе с корпусом машины
не помещается в разворотной зоне:

```text
turn_zone_width >= outward_extent + collision_radius
```

Для обычного двухдугового разворота `outward_extent = turn_radius`. Для
петлевого манёвра выход рассчитывается по геометрии трёх дуг и может быть
больше радиуса. `collision_radius` охватывает длину корпуса, ширину корпуса,
ширину захвата и запас безопасности, поэтому габариты учитываются при любом
угле машины на дуге.

## Расчёт времени

Время каждого сегмента:

```text
segment_time = segment_length / segment_speed
```

Время движения по радиальной дуге:

```text
arc_time = arc_angle × turn_radius / turn_speed
```

Время маршрута складывается из:

- рабочего движения;
- порожних переездов;
- разворотов;
- задержки запуска.

Основной показатель стратегии:

```text
makespan = max(time_machine_1, time_machine_2)
```

## Проверка столкновений

На каждом сегменте машина движется с постоянной скоростью. Для двух машин
рассматривается относительное движение:

```text
relative_position(t) = initial_distance + relative_speed × t
```

В пределах общего временного интервала аналитически находится момент
минимального расстояния.

Столкновение фиксируется при условии:

```text
distance <= collision_radius_1 + collision_radius_2
```

Проверяются:

- движение к первому проходу;
- рабочие проходы;
- развороты;
- ожидание на старте;
- положение машин после завершения работы.

## Подбор задержки запуска

Если одновременный запуск приводит к столкновению, проверяются задержки одной из
машин:

```text
0, 5, 10, ..., 180 секунд
```

Для каждой величины проверяются два варианта:

- задерживается первый комбайн;
- задерживается второй комбайн.

Выбирается безопасный вариант с минимальным `makespan`. Если конфликт не
устраняется, данная пара маршрутов отклоняется.

## Выбор лучшего плана

Планы сравниваются последовательно:

1. Минимальное время завершения последней машины.
2. Минимальный суммарный порожний пробег.
3. Минимальная площадь перекрытия.

Второй и третий критерии применяются, если времена отличаются не более чем на
`TIME_TIE_FRACTION`.

## Генерация сценариев

Для каждой характеристики первой машины задаётся отношение ко второй:

- `=` — параметры равны;
- `>` — параметр первой машины больше;
- `<` — параметр первой машины меньше.

Перебираются:

- ширина захвата;
- рабочая скорость;
- длина корпуса;
- ширина корпуса.

Для двух направлений проходов формируется:

```text
2 × 3⁴ = 162 сценария
```

## Осознанные ограничения

1. Машина представлена окружностью, а не точным прямоугольным контуром.
2. Не учитываются ускорение, торможение и буксование.
3. Рабочая скорость постоянна.
4. Движение задним ходом отсутствует.
5. После завершения машина остаётся на внешней границе поля.
6. Максимальная задержка старта ограничена 180 секундами.
