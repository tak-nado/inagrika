# Стенд ESP32-S3 на ESP-IDF и FreeRTOS

Это базовый локальный исполнитель для проекта `Prime`. Планировщик на ПК пока
не связан со стендом напрямую, поэтому первые команды передаются через UART.

Проект рассчитан на ESP-IDF 5.3 или новее и не использует Arduino.

## Алгоритм

1. `app_main()` настраивает GPIO, UART, I²C и аппаратный генератор импульсов
   LEDC для двух A4988.
2. Затем запускается одна задача FreeRTOS `control_task`.
3. Задача принимает команды движения и по очереди опрашивает два HC-SR04.
4. При препятствии ближе 25 см драйверы отключаются, состояние меняется на
   `SAFE_STOP`.
5. Каждые 500 мс отправляется строка телеметрии.

Импульсы `STEP` формируются периферией LEDC с частотой 400 Гц. Поэтому задача
FreeRTOS не тратит процессорное время на постоянное переключение GPIO.

## Команды UART

| Команда | Действие |
| --- | --- |
| `F` | Вперёд |
| `B` | Назад |
| `L` | Поворот на месте влево |
| `R` | Поворот на месте вправо |
| `S` | Остановка и сброс `SAFE_STOP` |

Скорость UART — 115200 бод.

## Пины по схеме

| Устройство | Сигнал | GPIO ESP32-S3 |
| --- | --- | ---: |
| Левый HC-SR04 | TRIG | 7 |
| Левый HC-SR04 | ECHO | 15 |
| Правый HC-SR04 | TRIG | 5 |
| Правый HC-SR04 | ECHO | 6 |
| Верхний A4988 | STEP | 42 |
| Верхний A4988 | DIR | 41 |
| Нижний A4988 | STEP | 0 |
| Нижний A4988 | DIR | 45 |
| Оба A4988 | ENABLE | 40 |
| MPU6050 | SDA | 20 |
| MPU6050 | SCL | 19 |

GPIO0 и GPIO45 участвуют в загрузке ESP32-S3. Если драйвер мешает запуску,
STEP/DIR второго двигателя нужно перенести на свободные обычные GPIO.

## Сборка и прошивка

Откройте ESP-IDF terminal и выполните из каталога `firmware/stand_basic`:

```powershell
idf.py set-target esp32s3
idf.py build
idf.py -p COM5 flash monitor
```

Номер COM-порта замените на порт своей платы.

## Питание стенда

- На `VMOT` A4988 требуется отдельное питание двигателей и конденсатор около
  100 мкФ возле каждого драйвера. Земля источника должна быть соединена с GND
  ESP32-S3.
- `RESET` и `SLEEP` A4988 должны быть соединены и подтянуты к `VDD`.
- Обычный HC-SR04 при питании 5 В выдаёт на `ECHO` уровень 5 В. Перед входом
  ESP32-S3 нужен делитель напряжения или преобразователь уровней.
- Перед первым запуском проверяйте направление двигателей с вывешенными
  колёсами. Направления меняются константами `MOTOR_1_FORWARD` и
  `MOTOR_2_FORWARD` в `main.c`.
